Lemonade Stand

Run the corner stand. Don’t go broke.

Start with $30. Buy supplies each morning, set your price, then open — the day runs on its own.

Start playing

How a day works

  1. Morning prep. Buy ingredients and set the classic lemonade price. You can only shop before the stand opens.
  2. Open for business. Each game hour (~1 real second) sells one classic lemonade if you have the stock.
  3. Close of day. The day ends at hour 24 or when you can’t fill an order. Ice melts overnight; everything else carries over.
  4. Stay solvent. If your balance hits zero and you can’t make a lemonade, the game is over.
